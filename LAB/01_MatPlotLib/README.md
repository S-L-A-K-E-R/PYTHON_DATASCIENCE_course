# Matplotlib - Advanced Python

Two independent Jupyter labs to learn scientific visualization by recreating target figures. Both notebooks provide datasets and leave the plotting code for students to discover.

## Lab 1 - Visual foundations

[![Open Lab 1 in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/S-L-A-K-E-R/PYTHON_DATASCIENCE_course/blob/master/LAB/01_MatPlotLib/01_Visual_Foundations.ipynb)

**Notebook:** [01_Visual_Foundations.ipynb](01_Visual_Foundations.ipynb)

Four challenges: line plots with legends, scatter plots and colorbars, overlapping density histograms, and a 2 x 2 monitoring dashboard. Data is prepared so you can focus on plotting.

## Lab 2 - Scientific visualizations

[![Open Lab 2 in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/S-L-A-K-E-R/PYTHON_DATASCIENCE_course/blob/master/LAB/01_MatPlotLib/02_Scientific_Visualizations.ipynb)

**Notebook:** [02_Scientific_Visualizations.ipynb](02_Scientific_Visualizations.ipynb)

Four challenges: error bars and annotations, heatmaps, contour plots, and 3D surfaces. Each exercise starts with a small dataset you create yourself, then uses the same technique on a larger supplied dataset.

## Getting started

**Google Colab:** click the badge of the lab you want. Run its setup cells. Missing datasets are automatically retrieved from this repository when internet access is available. Figures in the instructions are linked directly to their source images on GitHub. Save a copy of your completed notebook with the plots displayed.

**Local Jupyter / VS Code:**

1. Clone or download the repository, keeping the `LAB/01_MatPlotLib/` directory intact.
2. Open a terminal in `LAB/01_MatPlotLib/`.
3. With Python 3.10+, run `python -m pip install -r requirements.txt`.
4. Open the notebook for Lab 1 or Lab 2, complete its exercises, and save the executed notebook.

## Shared files

- `data/`: synthetic datasets used by both labs.
- `figures/`: target images for the eight exercises.
- `PREVIEW.png`: overview of all eight target figures.
- `requirements.txt`: local Python requirements.
