## Scientific visualizations

This notebook includes four challenges:
- Sensor calibration with error bars and annotations
- Heatmaps
- Filled contours and isolines
- 3D surfaces

**Learning approach:** make a tiny dataset first, plot it, then apply the same technique to the larger supplied dataset. Research Matplotlib methods yourself and keep your plotting code readable.

## Get started

1. Select **Open in Colab** above, or run the notebook locally.
2. Run the first import and dataset-helper cell.
3. Work through the small examples before attempting each full-size target.
4. Save the executed notebook with your completed figures.

The notebook automatically downloads the two required files from `LAB/01_MatPlotLib/data/` if they are not available locally. It uses the existing visual targets in `LAB/01_MatPlotLib/figures/`, displayed via GitHub image URLs. Internet access is needed for automatic downloads and remote reference images.

If working locally without internet access, clone the full repository. Keep the `LAB/01_MatPlotLib/data/` folder and open the notebook from `LAB/02_MatPlotLib/`.
